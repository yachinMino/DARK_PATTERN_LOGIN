# ログインさせてください

架空の文具店「余白ストア」の会員ログインを目指す、日本語のブラウザゲームです。Cookie、会員プラン、利用規約、認証を順に確認し、不要な登録を回避します。決済、実在サービスの認証、広告配信、データ送信は行いません。

クリア結果の「答え合わせを見る」から、全33種類の仕掛けの見分け方、回避手順、今回のプレイでの判定を確認できます。

## 開発と検証

React、TypeScript、Vite、CSS、Zustand、Vitest、Playwrightを使用しています。開発にはNode.js 24を使用します。

```sh
npm ci
npm run dev
```

```sh
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

PlaywrightはChromiumで複数シード、マウス、キーボード、スマートフォン相当のタッチ操作を検証します。シードを指定するには、保存のないブラウザで `/?seed=29` のように開きます。初回は基本構成で開始し、クリア後に「別の構成で遊ぶ」を選ぶと次のシードを生成します。初回のシードは165です。同じシードで同じ構成を再現できます。

## 構成

| パス | 役割 |
| --- | --- |
| `src/game/types.ts` | ステップ、イベント、操作の型を定義します。 |
| `src/game/config.ts` | ステージ、仕掛けの固有ID、ヒント、イベントの発動条件と優先順位を定義します。 |
| `src/game/engine.ts` | 進行、チェックポイント、イベント処理、履歴を更新します。 |
| `src/game/store.ts`、`src/game/storage.ts` | Zustandの状態をバージョン付きで保存し、復元時に構造と整合性を検証します。 |
| `src/game/scoring.ts` | 減点の配分とS〜Dの評価境界を設定します。 |
| `src/views/` | 各画面、共通ダイアログ、結果画面を描画します。 |
| `tests/`、`src/game/engine.test.ts` | ブラウザ操作とゲームロジックを検証します。 |
| `public/` | イラスト、アイコン、Cloudflare Pages用ヘッダーを配置します。 |

進行、表示待ちイベント、累積指標、設定、最近20件のクリア記録をブラウザ内に保存します。各画面内の未確定の選択と仮IDの入力値は画面内だけで扱います。破損した保存は初期状態に戻します。ゲーム内リセットでは設定とクリア記録を保持します。

## イベントと評価を変更する方法

1. ステップの追加時は `src/game/types.ts` の進行順と `src/game/config.ts` のステージ・ヒントを定義します。
2. 仕掛けの追加時は固有ID、発動箇所、回避の確定条件を `patterns` に登録します。任意イベントを伴う場合は `eventRules` に発動ステップ、発動条件、優先度、繰り返しの可否を定義します。
3. 画面は `dispatch` で誤操作、同意、重大な失敗、進行を通知します。ダイアログは `DialogHost` に追加します。保存形式に互換性のない変更を加える場合は、保存バージョンと検証処理を更新します。
4. 発動と解除の条件をVitestで、実画面の回避手段をPlaywrightで検証します。

評価は100点から、未回避の仕掛け、誤操作、不要な同意、ヒント、リトライ、30分を超えた時間に応じて減点します。不要な同意の減点は13点で、誤操作の3点と時間による減点の上限9点を上回ります。設定は `src/game/scoring.ts` にあります。

過去のクリア記録は当時の評価を保持します。更新前から進行中のプレイでは、追加された仕掛けのうち遭遇したものを評価に含めます。

## Cloudflare Pagesに公開する方法

Cloudflareの「Workers & Pages」からPagesのGit連携を選び、このリポジトリを指定します。プロジェクトのルートに以下の設定を適用します。Cloudflareの画面ではViteのプリセットが「React (Vite)」と表示される場合があります。

| 設定 | 値 |
| --- | --- |
| 本番ブランチ | `main` |
| フレームワーク | Vite |
| ビルドコマンド | `npm run build` |
| ビルド出力ディレクトリ | `dist` |
| Node.js | 24（`.node-version`） |

ビルド済みの `dist` は、Pagesのダイレクトアップロードにも使用できます。Git連携とダイレクトアップロードの手順は、[Cloudflare PagesのReactガイド](https://developers.cloudflare.com/pages/framework-guides/deploy-a-react-site/)と[ダイレクトアップロードの公式ガイド](https://developers.cloudflare.com/pages/get-started/direct-upload/)を参照してください。
